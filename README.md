# Limina

Limina is an MMO that utilizes ASCII-based graphics to create a vast, persistent world. It focuses on a unique text-based visual aesthetic, blending retro-style visuals with modern multiplayer interaction.

## Premise

In Limina, players navigate a world rendered entirely in ASCII characters. This minimalist approach allows for a deep focus on atmosphere, community, and player-driven narratives within a shared, evolving environment.

## Getting Started

This project is a Flutter application.

To run the project:

1. Ensure you have [Flutter](https://docs.flutter.dev/get-started/install) installed.
2. Run `flutter pub get` to fetch dependencies.
3. Run `flutter run` to start the application.

## Project Structure

- `lib/`: Contains the Flutter source code.
- `test/`: Contains unit and widget tests.
